# 协议变更记录（CHANGELOG）

> **本文件是协议版本变更的唯一记录**：协议版本号只在这里声明一次，规范正文引用它、不重复定义。
> 采用 Keep a Changelog 风格；**版本号只写协议版本**，与应用版本无关。
> 本文件**不写日期**：没确认过的日期不写，用「v1 冻结」「未冻结」这类描述代替。

## 0. 改协议时必须同时做的三件事

| # | 做什么 | 在哪里 | 为什么 |
|---|---|---|---|
| 1 | 改规范 | 对应域的规范正文（MUST / SHOULD + 字段表 + 数值表） | 规范是纸面契约，三端都照它实现 |
| 2 | 加 / 改向量 | 一致性向量（能给自动化步骤就给；给不出就先写人工检查项） | 「语义变更没有对应向量」是评审红线，向量是实现的唯一裁判 |
| 3 | 记这里 | 本文件的 `Unreleased` 小节 | 协议版本只能有一处声明 |

> 三件事**同一次提交**完成，缺一视为未完成。冻结主版本 = 打 tag；冻结后**只允许追加**。

## 1. 协议版本与应用版本的关系

| | 协议版本 | 应用版本 |
|---|---|---|
| 回答什么 | 两端**能否正确对话** | 这是**哪个发布包** |
| 形态 | `MAJOR.MINOR.PATCH`（本文件从 `1.0.0` 起记录） | 产品发布号，各端各自走 |
| 出现在哪 | 设备自述、配对响应、WS `hello`；v2 起还有协商头与路径前缀 | 请求头 `X-QS-Client-Version`、响应头 `X-QS-Server-Version`、body 的 `app_version` |
| 谁改它 | 改线缆契约才改 | 发版就改 |
| 现状的错 | 协商**比的是应用版本**的主版本（见 `1.0.0` 的 Changed 与 `Unreleased` 的 C1/C3） | —— |

- **MUST NOT** 用应用版本判断线缆兼容性；**MUST NOT** 把协议版本当发布号用。
- 换实现**不动**协议版本；扩协议**不必然**发应用版本。
- 协商头只取 `MAJOR.MINOR`；HTTP 路径只取 `MAJOR`。路径里出现的主版本与协商头里的主版本**必须一致**。
- **待确认**：版本号形态在本仓库内有两处口径 —— 一处写 `MAJOR.MINOR`，一处写 tag `vX.Y.0`。本文件按 `MAJOR.MINOR.PATCH` 记录（与 `1.0.0` 的起始要求一致），协商头与路径各取所需前缀。

## [1.0.0] — v1 冻结

**冻结范围**：把已发布的行为**照原样**写成规范（按实现反推），包括所有看起来不干净但已被接受的不对称语义。v1 不是设计，是记录；写它的时候不许顺手改良。

### Added

- 端点表（17 条）与路径前缀恒为 `/api/v1/`。
- 协商现状：请求头 `X-QS-Client-Version`（应用版本）；主机比较两端**应用版本的主版本**，字符串相等才放行；不一致回 `426 version_mismatch`；**完全不带该头一律放行**；**值不可解析也回 426**；检查顺序是**先鉴权、后版本**，且版本检查在**路由之前**；`/ws` **不参与**协商。
- 响应头 `X-QS-Server-Version`（所有 `/api/*` 响应，含错误；`/ws` 除外）。
- 协议版本自述：整数 `1`，在设备自述、配对响应、WS `hello` 三处同源；**没有任何一端依据它分支**。
- 能力自述：恒 5 项（分析、同步、取图、合集、多页），顺序不是契约，客户端**不据此分支**。
- 错误体三键 `{code, message, retry_after_seconds}`，该键恒在。
- 硬约束：单图 2 MiB、多页上限 6、上传 30 次 / 分钟 / 设备、配对码 5 分钟、5 次 / 分钟、连续 10 次失败锁 60 秒。

### Changed（相对旧契约文本的修正，全部按实现反推）

- `426` 的 body 里**没有**独立的版本字段：双方版本只出现在 `message` 文本里。
- 「除配对外的所有请求都要 token」不成立：设备自述同样免鉴权。
- 「主版本不一致」隐含只在带了头时判定：实现明确对**缺头请求放行**。
- 版本头「覆盖所有请求」不成立：`/ws` 完全绕过中间件，既无检查也无响应头。
- 端点、字段与数值若干处按实现补齐（队列深度上限、`cached`、`local_path` 等）。

### Removed

- 无。`1.0.0` 是首个冻结版本，此处不删任何东西；协议已发布的错误码**永不删除**，只能标记废弃。

## 版本记录格式（后续维护者照抄）
