## 术语（先落在纸上，正文引用）

| 术语 | 含义 |
|---|---|
| **Host** | 承担传输、配对、设备注册表、图片 Blob、任务队列、op 中继与水位的一方。**同一时刻同一局域网只有一个** |
| **客户端** | Host 的客户端：手机端 App、Windows 端的主界面 |
| **Provider** | 真正调用 AI 的一方（持有 API Key）。Windows 端同时是 Host 的客户端与 Provider；手机端两者都不是 |
| **任务 / 会话** | 一次识别 = 一条任务 + 一条结果会话；任务有生命周期，会话是可离线查看的历史记录 |
| **op** | 一次本地改动的可同步记录；Host 对它**不透明**，只按 Lamport 顺序记录与转发 |
| **水位** | Host 已记录的 op 时钟值；客户端发现水位上涨即拉取一次 |
