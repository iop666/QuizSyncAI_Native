## 写作要求

1. 每条规则可验收：要么能写成一个向量，要么能写成一个人工检查项。
2. 涉及「看起来不合理但已被用户接受」的行为，标注 `契约`（必须照做）或 `待验证假设`（尚未在真机确认），不许含糊。
3. 数字（上限、超时、限流）必须与 `09-errors.md`、`02-transport.md` 一致，冲突时以本目录内的交叉引用为准并立刻修掉重复定义。
