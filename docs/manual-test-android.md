# Android 真机人工测试清单（M5 交付）

> 本机没有 Android 设备也没有模拟器，**本清单所列全部为「未验证」状态**。
> 逐步执行；每步包含「操作 → 预期 → 失败时看什么」。建议用 `adb logcat | grep -E "CaptureService|CaptureBridge|A11yCapture|flutter"` 伴跑。

## 准备

- [ ] Windows 端（同一局域网）启动 QuizSync，设置页填好 AI Key，**新建/进入一个任务合集**，
      记下二维码与配对码
- [ ] Android 端安装 `app-arm64-v8a-release.apk`

## 1. 配对

- [ ] **操作**：Android 打开 App → 扫 Windows 设置页的二维码
- [ ] **预期**：进入主页；Windows 设置页「已配对设备」出现手机
- [ ] **失败看**：扫码无反应 → 手动输入 `IP:端口` + 配对码；仍失败查 Windows 防火墙对 8765 端口的放行

## 1.1 底部三标签与当前任务页（用户需求 6）

- [ ] **操作**：打开 App，观察底部
- [ ] **预期**：三个标签「当前任务 / 历史记录 / 设置」，默认停在**当前任务**；未开始时显示
      「已连接电脑，但未开始任务」；拔掉 Wi-Fi 后显示「未连接电脑」；Windows 端**不选合集**时
      显示需要选合集的提示
- [ ] **失败看**：文案与实际状态不符 → 检查 `/api/v1/info` 的 `active_collection_id`

## 1.2 识别模块开关（用户需求 11）

- [ ] **操作**：设置 → 识别模块（默认**关闭**）
- [ ] **预期**：关闭时悬浮球不显示、当前任务页提示「识别模块已关闭」并给一键开启；
      打开后其下方出现「识别模块设置」二级页（截屏方式 / 悬浮球开关与大小透明度 /
      权限引导 / 图片缓存上限）
- [ ] **失败看**：开关状态与悬浮球实际显隐不一致 → 检查设置持久化与 `CaptureBridge` 调用

## 2. 权限引导

- [ ] **操作**：识别模块设置 → 权限引导 → 逐项授予通知、悬浮窗、电池优化白名单
- [ ] **预期**：每项都能跳到对应系统设置页，且返回后显示**真实**授予状态；「通知」在授权截屏后
      出现「QuizSync 截屏服务运行中」常驻通知
- [ ] **失败看**：`adb shell dumpsys notification | grep quizsync`

## 3. 首次截屏授权（只弹一次）

- [ ] **操作**：点悬浮球（首次）
- [ ] **预期**：弹出系统「屏幕录制」授权框 → 允许后**不再弹出**，直接截屏分析；通知栏出现截屏服务常驻通知
- [ ] **失败看**：logcat `CaptureService`；确认通知权限已授予（Android 14+ 未授予通知时前台服务无法启动）

## 4. 单击截屏不弹窗

- [ ] **操作**：授权后再点悬浮球 3 次（间隔几秒）
- [ ] **预期**：每次都直接进入分析，无任何系统弹窗
- [ ] **失败看**：若再次弹授权框 → 会话未被复用，查 `CaptureService.projectionReady` 相关日志

## 5. 悬浮球不出现在截图里

- [ ] **操作**：截屏完成后查看结果页图片/分析内容是否包含绿色悬浮球残影
- [ ] **预期**：截图干净（截前隐藏球 + 250ms 等待生效）
- [ ] **失败看**：低端机可能需要更长隐藏等待（当前 250ms），报告机型

## 6. 拖动不误触发截屏

- [ ] **操作**：按住悬浮球拖动到屏幕另一侧松手
- [ ] **预期**：球吸附到最近边缘；**不**触发截屏分析
- [ ] **失败看**：若拖完就出结果 → 8dp 阈值判定问题

## 7. 悬浮球手势：单击 / 长按 / 多页（用户需求 11）

- [ ] **操作**：单击悬浮球
- [ ] **预期**：截一张图 → 单图上传分析（主机已选合集时）
- [ ] **操作**：长按悬浮球（多页模式第 1 页）→ 换到题目下一页 → 再长按 → 再换页 → 长按
- [ ] **预期**：每次长按都截一页并**立即上传**该页（当前任务页显示已累积页数）；到上限（默认 6）时
      提示「已达上限」并**自动**创建多页任务
- [ ] **操作**：长按两次后，**短按一次**
- [ ] **预期**（M49 起与 Windows 端热键一致）：短按**只提交已经截好的页**，**不再多截一张**；
      识别到的页数 = 长按次数（此例为 2），结果是一份合并后的识别记录
- [ ] **失败看**：logcat 中 `CaptureBridge` 的 tap/longPress 回调与 `.jpg` 上传顺序；
      主机端会话页数应等于上传页数

## 7.1 多页结果与自动刷新（用户需求 1/7）

- [ ] **操作**：在主机构建多页识别后观察手机
- [ ] **预期**：当前任务页**自动**刷新并显示「N 张图片识别中…」；完成后自动显示答案；
      结果页一页显示全部题目，底部是「上一次识别 / 下一次识别」，可点「重新生成」让主机重跑
- [ ] **失败看**：若需手动下拉才刷新 → WS 事件监听（`task_update` / `task_result` / `ops`）未生效

## 7.2 题目不全与 AI 猜测（用户需求 2/3）

- [ ] **操作**：故意只截半道题（选项被截断）让主机识别
- [ ] **预期**：题目卡片**黄框** + 「题目不全」横幅；答案若有则标注「AI 猜测」；
      卡片标题形如「3. 第 12 题」（序号在前、识别到的题号在后）；只有答案没有题干的内容不显示
- [ ] **失败看**：`questions.incomplete` / `answer_guessed` 是否入库

## 8. 后台被杀后恢复

- [ ] **操作**：最近任务划掉 App → 重新打开
- [ ] **预期**：悬浮球恢复显示（识别模块开启时）；历史记录仍在（本地库）
- [ ] **失败看**：悬浮球不出现 → 检查悬浮窗权限与电池白名单

## 8.1 历史分组、删除与导出（用户需求 8/9/13）

- [ ] **预期**：先按**合集**分组（未归属的进「未分类」），点进合集看到该合集的记录，点进记录看题目

## 17. 状态栏/导航栏跟随主题（M10 反馈 7 + M11 反馈 11 + **M13 重做**）

- [ ] **操作**：设置 → 主题：浅色 ↔ 深色 来回切；再把主题设为「跟随系统」并切系统深色
