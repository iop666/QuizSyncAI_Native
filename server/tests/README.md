# tests —— 测试策略

Phase 2 起在此建立（xUnit）。三层：

| 层 | 内容 | 用什么 |
|---|---|---|
| 向量回放 | 逐条回放 `QuizSyncProtocol/conformance/vectors/*.ndjson`：配对 / 鉴权 / 上传 / 任务 / sync 收敛 / 错误 | 回放器只做 I/O 适配，不含业务逻辑 |
| 集成 | 起真的 Kestrel 监听回环随机端口，走完整链路：配对 → 上传 → 建任务 → 收结果 → 同步 op | xUnit + 真 HTTP/WS 客户端 |
| 兼容 | v1 客户端（或等价的旧协议客户端）对新 Server 的全链路 | 以**现有 Flutter 1.1.0 客户端为裁判**逐条对 |

## 规矩

- 向量失败 = 实现错，不许改向量让测试变绿（要改向量必须同时改规范并说明理由）。
- 覆盖「看起来不该这样、但用户已经接受」的语义时，用例名字里写明这是契约，并链接规范条目。
- 内嵌模式与独立模式各跑一遍同一批向量，结果必须一致；时延差异记录在案。
