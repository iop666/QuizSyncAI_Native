# src —— 计划中的两个工程

Phase 0 只建骨架，**不写产品代码**（`.NET SDK` 本机尚未安装，见根 README §7）。目录在 Phase 2 开始时创建。

| 工程 | 类型 | 职责 |
|---|---|---|
| `QuizSync.Server.Cli/` | 可执行程序 | 命令行入口、`setup` 向导、随登录启动、`doctor`、日志输出、进程控制（`runtime.json`） |
| `QuizSync.Server.Core/` | 库 | Host 的全部能力：传输、配对与令牌、设备注册表、图片 Blob、任务队列与结果缓存、op 中继与水位、快照分页、识别任务派发 |

## 分层纪律

- `Cli` **只做**参数解析、终端输出、进程生命周期；**不含**任何协议逻辑。
- `Core` 不知道「自己是被 CLI 加载还是被客户端内嵌」：不读命令行参数、不直接写控制台、不假设进程只有一个。
- 所有对外行为都要能通过 `Core` 的公开接口在进程内测试（集成测试起真 Server 监听回环地址）。
